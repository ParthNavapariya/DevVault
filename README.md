
# DevVault – Centralized Public API Marketplace

DevVault is a centralized platform where API providers can publish APIs and developers can discover, explore, and subscribe to them.

## Technology Stack

- Frontend: HTML, CSS, Bootstrap, JavaScript
- Backend: Python, Django REST Framework
- Database: MySQL
- Version Control: Git and GitHub

## Project Structure

- `frontend/` – User interface
- `backend/` – Backend application and REST APIs
